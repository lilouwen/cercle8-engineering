# Contributing

Corrections to technical writing and safe diagrams are welcome.

1. Do not publish or request commercial application source code.
2. Separate implemented, historically tested, planned and still-unverified features.
3. Reference actual dated evidence for claims about tests or behavior.
4. Keep the main README concise; put case-study details in the relevant guide.
5. Never include secrets, customer data, private URLs or unredacted screenshots.
