## How to interpret evidence

**Recorded:** historical engineering notes describe the event or implementation.  
**Built/static checks:** lint, type-check or build was reported successful at that point.  
**End-to-end verified:** a real, scoped integration or user journey has been tested with recorded results.  
**Planned/validation pending:** no claim of completed or production-ready operation is made.
